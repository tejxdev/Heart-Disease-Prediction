# Heart-Disease-Prediction
💓 Heart Disease Prediction
This project uses Machine Learning to predict the likelihood of a person having heart disease based on medical parameters. It includes a user-friendly web interface and runs on localhost.

🚀 Features
Predict heart disease using machine learning

Interactive web UI for input and result display

Trained on publicly available heart disease datasets

Deployable on localhost for testing/demo

🧠 Technologies Used
Python

Pandas, NumPy – for data manipulation

Scikit-learn – for model training and evaluation

Flask – for building the backend server

HTML, CSS, Bootstrap – for frontend

Jupyter Notebook – for data exploration and model building

📊 Dataset
The dataset used is from the UCI Heart Disease Dataset, which includes the following features:

Age

Sex

Chest Pain Type

Resting Blood Pressure

Serum Cholesterol

Fasting Blood Sugar

Resting ECG

Maximum Heart Rate

Exercise Induced Angina

ST depression

Number of major vessels

Thalassemia
